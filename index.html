Preencha os dados do cliente (ou carregue de uma cotação) e emita o documento. Assinatura em migração para o Clicksign (DocuSign pausado) — configure o link em Configurações → Assinatura.
⚙️ O que cada botão faz
• 🎟️ Gerar Voucher (PDF) → cria o voucher da Magiway em página A4, fonte grande: dados do cliente, dados logísticos (voos/horários e cadeirinha), valor, um campo grande de observações e o QR Code do Guia do Cliente. Abre pronto para Imprimir / Salvar PDF.
• 📝 Contrato (Clicksign) → abre a caixa com a mensagem pronta + o link de assinatura do contrato para enviar ao cliente (WhatsApp/copiar).
Assinatura em migração para o Clicksign (DocuSign pausado). Cole o link do Clicksign em Configurações → Assinatura (Clicksign) e ative para os botões funcionarem.
